# Project guidance

This repository is the v0.01 concept preview of Loop for Scientific Research. It contains a project proposal, an architecture illustration, and manual handoff templates. It does not yet contain an executable research orchestrator or an installable Skill.

- Keep public documentation, templates, and source comments in English; maintain README.zh-CN.md as the Chinese homepage translation.
- Separate implemented repository artifacts from proposed capabilities. A diagram, CLI entry point, or existing related project does not demonstrate a working integration.
- Preserve the distinction between native Codex subagents and external model sessions. The proposed advisor bridge has not been validated here.
- Keep the researcher's goals and evidence visible. Model agreement alone is not scientific validation.
- Do not publish private research, application documents, credentials, machine paths, full conversations, or software environments.
- Keep the first release small. Add executable integration only when that work is explicitly requested, with appropriate validation.
- The editable diagram source is assets/source/build_overview.py. Regenerate assets/overview.svg after editing it and inspect a rendered image.
